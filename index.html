Connexion API Epic / Fortnite (optionnel)

Récupère automatiquement tes stats depuis l'API publique fortnite-api.com. Il te faut une clé gratuite (crée un compte sur le site) et ton compte Epic doit avoir les statistiques publiques (Paramètres Epic → Confidentialité).

Tes données sont stockées uniquement dans ton navigateur (localStorage). Rien n'est envoyé sur un serveur, sauf si tu utilises l'API.
