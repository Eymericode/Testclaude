🔄 Synchroniser mes parties

L'app récupère automatiquement les parties jouées depuis ton compte Epic — aucune saisie manuelle. Clique une première fois pour enregistrer ton point de départ, puis reviens après avoir joué : tes nouvelles parties s'ajoutent toutes seules.

🔑 Configure ton compte Epic d'abord

Renseigne ta clé API et ton pseudo Epic dans l'onglet Données / API (une seule fois).

ℹ️ Epic ne fournit pas le détail de chaque partie, seulement tes totaux. La synchro enregistre donc l'ensemble des parties jouées depuis la dernière synchro (nombre de parties, kills, victoires, classements).

Connexion API Epic / Fortnite (optionnel)

Récupère automatiquement tes stats depuis l'API publique fortnite-api.com. Il te faut une clé gratuite (crée un compte sur le site) et ton compte Epic doit avoir les statistiques publiques (Paramètres Epic → Confidentialité).

🔐 API officielle Epic (avancé)

Utilise l'API officielle Epic via ton backend sécurisé (Cloudflare Worker). Suis le guide dans epic-proxy/README.md pour le déployer, puis colle son URL ici.
